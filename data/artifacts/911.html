Key ideas

Frequency distribution

A table that shows each value (or class of values) alongside its frequency — how many times it occurs. The frequencies add up to the total number of observations N.

Class interval

When data is spread over a wide range, values are grouped into equal class intervals such as 0–10, 10–20, … The class width h is upper limit − lower limit; the class mark (mid-value) is (lower + upper)/2.

Bar graph vs histogram

A bar graph shows discrete/categorical data with equal-width bars separated by gaps; only the height matters. A histogram shows grouped continuous data with bars that touch (no gaps); the width spans the class interval and the area represents the frequency.

Frequency polygon

Join the tops of the histogram bars — the points are the class marks plotted against frequency. The polygon is closed by extending to class marks of imaginary classes (one below and one above) so it meets the x-axis.

Pie chart

A circle split into sectors, one per category. The angle of each sector is (frequency ÷ total) × 360°. All the sector angles add up to 360°.

Ogive (cumulative frequency curve)

A less-than ogive plots the less-than cumulative frequency against the upper class boundary and joins the points into a rising curve. Reading across from N/2 gives the median of the grouped data.
