Isotopes — same element, different mass

IsotopeProtons (Z)NeutronsElectronsMass No. A

  • Same Z → same number of protons & electrons → same chemistry.
  • Different N → different mass number A (A = Z + N). Only the mass changes.
  • Some isotopes are radioactive (e.g. Tritium, C-14 used in carbon dating).

Key Facts

  • Proton: charge +1, mass ~1 u, in the nucleus. Number of protons = Atomic Number (Z).
  • Neutron: charge 0, mass ~1 u, in the nucleus.
  • Electron: charge −1, mass ~1/1840 u, orbits in shells around the nucleus.
  • Mass Number A = protons + neutrons (Z + N).
  • Neutral atom: electrons = protons. Ion: electrons ≠ protons (cation if fewer electrons, anion if more).
  • Shell rule (Bohr-Bury): maximum electrons = 2n² → K=2, L=8, M=18 (but 8 while it is the outermost for Z≤20), N=8.
  • Isotopes: atoms of the same element (same Z) with different numbers of neutrons.
  • Octet: 8 electrons in the outermost shell (2 for H/He) → stable, unreactive (noble gases).
