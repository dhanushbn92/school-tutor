Solve a Simple ODE (Variable Separable)

dy/dx = k·y

Separate the variables and integrate:

dy/y = k dx
∫dy/y = ∫k dx
ln|y| = kx + c
y = C·e^(kx)

Solution y = C·e^(kx). k>0 → exponential growth; k<0 → exponential decay; k=0 → constant.

Key Facts

Order
The order of the highest derivative appearing in the equation. e.g. d²y/dx² + y = 0 has order 2.
Degree
The power (exponent) of the highest-order derivative, after the equation is made a polynomial in derivatives (no radicals or fractional powers on them). If it can't be, the degree is not defined.
General solution
Contains arbitrary constants (as many as the order). It represents a whole family of curves — e.g. y = Ce^(kx).
Particular solution
Obtained by fixing the constants using an initial/boundary condition — one specific curve through a given point.
Variable separable
An ODE that can be written g(y) dy = h(x) dx, then solved by integrating each side.
