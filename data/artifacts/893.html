Key facts — line in space

  • Vector form: a line through point A with direction d is r = A + t·d, where t is a real parameter.
  • Symmetric / Cartesian form: (x−x₁)/a = (y−y₁)/b = (z−z₁)/c, where (a, b, c) are the direction ratios. Direction cosines are (a, b, c)/√(a²+b²+c²).
  • Through two points P, Q: direction d = Q − P, so (x−x₁)/(x₂−x₁) = (y−y₁)/(y₂−y₁) = (z−z₁)/(z₂−z₁).
  • Angle between lines: cos θ = (d₁·d₂)/(|d₁||d₂|) = |a₁a₂+b₁b₂+c₁c₂| / (√Σa₁²·√Σa₂²).
  • Parallel: a₁/a₂ = b₁/b₂ = c₁/c₂ (d₁×d₂ = 0). Perpendicular: a₁a₂+b₁b₂+c₁c₂ = 0.
  • Skew lines are non-parallel lines that do not intersect. Shortest distance = |(A₂−A₁)·(d₁×d₂)| / |d₁×d₂|, using the scalar triple product.
  • Intersecting lines have shortest distance 0, i.e. (A₂−A₁)·(d₁×d₂) = 0 while d₁×d₂ ≠ 0.

Quick check (3 questions)

1. The line (x−2)/3 = (y+1)/(−4) = (z)/5 has direction ratios:

In (x−x₁)/a = (y−y₁)/b = (z−z₁)/c the denominators (3, −4, 5) are the direction ratios; the point on the line is (2, −1, 0).

2. Two lines with directions (1, 2, 2) and (2, −2, 1) are:

d₁·d₂ = 1·2 + 2·(−2) + 2·1 = 2 − 4 + 2 = 0, so the lines are perpendicular.

3. Shortest distance between skew lines r = A₁ + t·d₁ and r = A₂ + s·d₂ is:

The common perpendicular is along d₁×d₂; projecting A₂−A₁ onto its unit vector gives SD = |(A₂−A₁)·(d₁×d₂)| / |d₁×d₂|.
