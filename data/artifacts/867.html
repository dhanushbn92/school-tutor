The Domino Intuition

Induction works like a line of dominoes. Two things guarantee all of them fall:

1. Base case

We physically push the first domino. This is P(1) — we prove the statement is true for n = 1.

2. Inductive step

Each domino is close enough that if domino k falls, it topples k+1. This is “P(k) ⇒ P(k+1)”.

The conclusion

Base + step ⇒ every domino falls. So P(n) is true for all n ≥ 1, no matter how long the row.

Checking Cases ≠ Proving

Testing many values of n builds confidence, but it is never a proof — a statement can hold for the first thousand cases and still fail. Only the base case + inductive step covers all n at once.

The trap

n²+n+41 (Euler) is prime for n = 0,1,2,…,39 — forty straight hits! But at n = 40 it equals 41². Checking cases missed it.

Why induction is stronger

The inductive step P(k)⇒P(k+1) is a single argument that simultaneously covers infinitely many n. No finite table can.

Both parts are essential

Base case without the step, or step without the base, proves nothing. You need both links to topple the whole row.
