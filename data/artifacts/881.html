Why restrict the domain?

A function has an inverse only if it is one-one (each output comes from just one input). Over all real numbers, sin x repeats, so a horizontal line hits it many times — not one-one. Drag the horizontal line and watch how many times it cuts the curve.

Key identities

  • sin⁻¹x + cos⁻¹x = π/2, for x ∈ [−1, 1]
  • tan⁻¹x + cot⁻¹x = π/2, for all real x
  • sec⁻¹x + csc⁻¹x = π/2, for |x| ≥ 1
  • sin⁻¹(−x) = −sin⁻¹x, tan⁻¹(−x) = −tan⁻¹x (odd)
  • cos⁻¹(−x) = π − cos⁻¹x, cot⁻¹(−x) = π − cot⁻¹x
  • sin⁻¹(1/x) = csc⁻¹x, cos⁻¹(1/x) = sec⁻¹x (|x| ≥ 1)
