Key facts

Relation

A relation R from set A to set B is any subset of the cartesian product A×B. It simply pairs some elements of A with some of B — no restriction on how many.

Function

A function f: A→B is a special relation in which every element of A is paired with exactly one element of B. No element of A may be left out, and none may have two images.

Domain, Codomain, Range

Domain = set A (all inputs). Codomain = set B (the declared target set). Range = the subset of B that is actually reached, i.e. { f(x) : x ∈ A }. Always range ⊆ codomain.

One-one (injective)

f is one-one if distinct inputs give distinct outputs: f(x₁)=f(x₂) ⟹ x₁=x₂. No two arrows land on the same element of B.

Onto (surjective)

f is onto if every element of the codomain B is an image of some element of A — i.e. range = codomain. No element of B is left unhit.

Bijective & composition

A function that is both one-one and onto is bijective; only bijections have an inverse f⁻¹. Composition: (g∘f)(x)=g(f(x)), applying f first, then g.
