What each type means
  • Row: only one row (1×n). Column: only one column (m×1).
  • Square: rows = columns. Diagonal: square, all off-diagonal entries 0.
  • Scalar: diagonal with all diagonal entries equal. Identity (I): scalar with that value = 1.
  • Zero (null): every entry is 0. Symmetric: Aᵀ = A. Skew-symmetric: Aᵀ = −A (diagonal all 0).

Order & Rules of Operations

When is each operation defined?
  • Addition / subtraction (A ± B): only when A and B have the same order. Add entrywise.
  • Scalar multiple (kA): always defined; multiply every entry by k. Order unchanged.
  • Product (A × B): defined only when columns of A = rows of B. If A is m×n and B is n×p, then AB is m×p.
  • Transpose (Aᵀ): always defined; an m×n matrix becomes n×m (rows and columns swapped).

Matrix multiplication is not commutative: AB ≠ BA in general

Take A = [[1,2],[3,4]] and B = [[0,1],[1,0]].

Quick facts panel
  • Order of a matrix = (number of rows) × (number of columns).
  • Element aij sits in row i, column j.
  • Addition rules: A+B = B+A (commutative); (A+B)+C = A+(B+C) (associative).
  • Scalar rules: k(A+B) = kA + kB; (k+l)A = kA + lA.
  • Product rules: (AB)C = A(BC); A(B+C) = AB + AC; but AB ≠ BA generally.
  • Transpose rules: (Aᵀ)ᵀ = A; (A+B)ᵀ = Aᵀ + Bᵀ; (AB)ᵀ = BᵀAᵀ.
