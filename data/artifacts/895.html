Why contrapositive ≡ conditional

Compare the truth-table columns for p⇒q and ¬q⇒¬p — they are identical in every row. The converse and inverse are also equivalent to each other, but not to the original.

p⇒q  ≡  ¬q⇒¬p (contrapositive)
q⇒p  ≡  ¬p⇒¬q (converse ≡ inverse)
p⇒q  ≠  q⇒p (a conditional is not equivalent to its converse)

Quantifiers

"For all" (∀) and "there exists" (∃), and how to negate them.

Universal ∀
∀x, P(x): "For all x, P(x) holds."
Example: ∀x∈ℕ, x+1 > x.
Negation:
¬(∀x, P(x)) ≡ ∃x, ¬P(x)
Existential ∃
∃x, P(x): "There exists an x with P(x)."
Example: ∃x∈ℕ, x is even.
Negation:
¬(∃x, P(x)) ≡ ∀x, ¬P(x)

Negating a quantifier flips it (∀↔∃) and negates the inside.

Connectives

  • NOT ¬p — negation: true when p is false.
  • AND p∧q — conjunction: true only when both true.
  • OR p∨q — disjunction: false only when both false (inclusive OR).
  • IF-THEN p⇒q — conditional: false only when p is true and q is false.
  • IFF p⇔q — biconditional: true when p and q have the same truth value.

Converse / Inverse / Contrapositive

  • Conditional: p⇒q
  • Converse: q⇒p
  • Inverse: ¬p⇒¬q
  • Contrapositive: ¬q⇒¬p — equivalent to the original.
  • Converse ≡ Inverse (both differ from original).

Quantifiers

  • ∀ "for all" — universal quantifier.
  • ∃ "there exists" — existential quantifier.
  • ¬(∀x,P) ≡ ∃x,¬P
  • ¬(∃x,P) ≡ ∀x,¬P
  • Tautology: true in every row. Contradiction: false in every row. Contingency: sometimes true, sometimes false.
