Integration reverses differentiation

If d/dx [ F(x) ] = f(x), then ∫ f(x) dx = F(x) + C. The +C appears because every curve shifted vertically has the same slope. Tap a standard integral below to reveal it.

The “+C” family — parallel curves, one slope

All these curves are anti-derivatives of the same function. At the tick position their tangents are exactly parallel — the value of C only slides the curve up or down.

Common slope at x = 1.00 is f(x) = 1.00. Each dashed tangent has this identical gradient.

Basic techniques

Substitution (u-substitution)

Reverses the chain rule. Let u = g(x), so du = g′(x) dx.

Rule: ∫ f(g(x))·g′(x) dx = ∫ f(u) du

Worked: evaluate ∫ 2x·(x²+1)³ dx

• Let u = x²+1 ⟹ du = 2x dx.

• Integral becomes ∫ u³ du = u⁴/4 + C.

• Back-substitute: = (x²+1)⁴ / 4 + C.

Integration by parts

Reverses the product rule.

Rule: ∫ u dv = u·v − ∫ v du

Worked: evaluate ∫ x·eˣ dx

• Choose u = x (⟹ du = dx) and dv = eˣ dx (⟹ v = eˣ).

• Apply: x·eˣ − ∫ eˣ dx.

• = x·eˣ − eˣ + C = eˣ(x − 1) + C.

Tip (LIATE): pick u as the earliest of Log, Inverse-trig, Algebraic, Trig, Exponential.

Facts panel

  • Anti-derivative: integration undoes differentiation. If F′=f then ∫f dx = F + C.
  • Power rule: ∫ xⁿ dx = xⁿ⁺¹/(n+1) + C for n ≠ −1.
  • The n = −1 case: ∫ (1/x) dx = ln|x| + C.
  • Exponential: ∫ eˣ dx = eˣ + C;  ∫ aˣ dx = aˣ/ln a + C.
  • Trig: ∫ sin x dx = −cos x + C,  ∫ cos x dx = sin x + C,  ∫ sec²x dx = tan x + C.
  • Constant & sum: ∫ k·f dx = k∫f dx;  ∫(f±g)dx = ∫f dx ± ∫g dx.
  • The “+C”: the constant of integration — infinitely many parallel anti-derivatives share one slope function.
  • Area interpretation: the definite integral ∫ab f dx is the signed area between the curve and the x-axis; area below the axis counts negative.
  • Fundamental Theorem: ∫ab f dx = F(b) − F(a), where F is any anti-derivative of f.
  • Convergence: as the number of rectangles n → ∞, the Riemann sum → the exact definite integral.
