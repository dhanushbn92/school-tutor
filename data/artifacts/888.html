The signed area ∫ₐᵇ f(x) dx counts regions below the x-axis as negative. As you raise n, the Riemann sum converges to the exact FTC value. Set a > b and the value flips sign.

The accumulation function A(x) = ∫ₐˣ f(t) dt measures signed area from a to x. The Fundamental Theorem says A′(x) = f(x): the slope of the blue accumulation curve at any x equals the height of f there. Move the probe to check.

Worked example: area between two curves

Region between y = 2 − x² (upper) and y = x (lower). Intersections: 2−x² = x ⇒ x²+x−2 = 0 ⇒ (x+2)(x−1)=0, so x = −2 and x = 1.

Area = ∫₋₂¹ [(2 − x²) − x] dx = [2x − x³⁄3 − x²⁄2]₋₂¹ = 9⁄2 = 4.5 square units (confirmed numerically: —).

Key facts

  • Definite integral: ∫ₐᵇ f(x) dx = F(b) − F(a) where F′ = f. The result is a number, not a function; the constant of integration cancels.
  • Fundamental Theorem of Calculus: if A(x) = ∫ₐˣ f(t) dt then A′(x) = f(x). Differentiation and integration are inverse operations.
  • Signed area: parts of the graph below the x-axis contribute negative area. For total geometric area use ∫|f|.
  • Reversal: ∫ₐᵇ f = −∫ᵇₐ f, and ∫ₐᵃ f = 0.
  • Additivity: ∫ₐᵇ f = ∫ₐᶜ f + ∫꜀ᵇ f for any c.
  • Linearity: ∫ₐᵇ [k·f + g] = k∫ₐᵇ f + ∫ₐᵇ g.
  • Symmetry on [−a, a]: even f ⇒ ∫₋ₐᵃ f = 2∫₀ᵃ f; odd f ⇒ ∫₋ₐᵃ f = 0.
  • Area between curves: ∫ₐᵇ [ f_top − f_bottom ] dx between intersection points.
