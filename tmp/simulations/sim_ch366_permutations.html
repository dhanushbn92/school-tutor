Formula & Facts Panel

Factorial
n! = n x (n-1) x ... x 2 x 1, and by definition 0! = 1.
Permutation (order matters)
nPr = n! / (n - r)! = n x (n-1) x ... x (n - r + 1). Number of ordered arrangements of r items from n.
Combination (order ignored)
nCr = n! / [ r! (n - r)! ] = nPr / r!. Number of ways to choose r items from n.
Relation
nCr = nCr(n-r) (symmetry), and nPr = r! x nCr.
With repetition allowed
r items from n with repetition: ordered = n^r; the plate/PIN counting principle.
Word arrangements
Letters of a word with repeats: n! / (p! q! ...).
Circular
n distinct objects in a circle: (n - 1)!.
When to use which?
Ask: does order/rank/position matter? Yes → permutation. Just a group/committee/selection? → combination.
