The Taxonomic Hierarchy

From broad to specific. Tap a rung to learn what it means. Example: the human being.

Tap any rung to read about it. Going down, groups get smaller and members more alike.
Binomial nomenclature — devised by Carolus Linnaeus. Every species gets a two-part Latin name: Genus + species. Human = Homo sapiens. The Genus is capitalised, species is lowercase, and the whole name is italicised (or underlined when handwritten).

Key Facts

Five Kingdoms: R.H. Whittaker (1969) grouped all life into Monera, Protista, Fungi, Plantae and Animalia, based on cell structure, body organisation and mode of nutrition.
Taxonomic hierarchy: Kingdom → Phylum (Division in plants) → Class → Order → Family → Genus → Species. Species is the basic unit of classification.
Binomial nomenclature: Carolus Linnaeus gave each organism a two-word scientific name (Genus + species) in Latin, so scientists worldwide use one common name.
