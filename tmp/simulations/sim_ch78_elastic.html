Three elastic moduli

Young's modulus Y = longitudinal stress / longitudinal strain = (F/A)/(ΔL/L)
Bulk modulus K = volume stress / volume strain = −ΔP / (ΔV/V)
Shear modulus η = shear stress / shear strain = (F/A) / (Δx/L) = (F/A)/θ

Key formulas & definitions

Stress σ = F / A  (N/m² = Pa)
Strain ε = ΔL / L  (dimensionless)
Hooke's law: within elastic limit, stress ∝ strain
Young's modulus Y = σ / ε = (F·L)/(A·ΔL)
Bulk modulus K = −P / (ΔV/V)
Shear (rigidity) modulus η = (F/A) / θ
Poisson's ratio ν = (lateral strain)/(longitudinal strain) = −(Δd/d)/(ΔL/L)
Elastic P.E. / volume u = ½ · σ · ε = ½ Y ε²
