Facts panel — six standard derivatives & the chain rule

d/dx sin x = cos x
d/dx cos x = −sin x
d/dx tan x = sec² x
d/dx cot x = −cosec² x
d/dx sec x = sec x tan x
d/dx cosec x = −cosec x cot x
Chain rule: d/dx f(g(x)) = f′(g(x)) · g′(x). E.g. d/dx sin(2x) = 2cos(2x), d/dx cos(x²) = −2x·sin(x²).

Q1. What is d/dx (cos x) ?
sin x
−sin x
sec² x
Correct: −sin x. The slope of cos x is the negative of sin x.
Q2. What is d/dx (tan x) ?
−cosec² x
sec x tan x
sec² x
Correct: sec² x. Since tan x = sin x / cos x, the quotient rule gives sec² x.
Q3. Using the chain rule, d/dx sin(2x) = ?
2 cos(2x)
cos(2x)
2 sin(2x)
Correct: 2 cos(2x). Outer derivative cos(2x) times inner derivative g′(x)=2.
