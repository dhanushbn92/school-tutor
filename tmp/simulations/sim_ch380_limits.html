Facts & Formulas

  • Limit: lim x→a f(x) = L means f(x) gets arbitrarily close to L as x nears a (from either side), x ≠ a.
  • LHL & RHL: the limit exists only if the left-hand limit f(a⁻) equals the right-hand limit f(a⁺).
  • Continuity at a needs all three: (1) f(a) is defined, (2) lim x→a f(x) exists, (3) the limit equals f(a).
  • Removable discontinuity: limit exists but ≠ f(a) (or f(a) undefined) — a single "hole".
  • Jump: LHL ≠ RHL, both finite. Infinite: f blows up (a vertical asymptote).
  • Standard limits: lim x→0 (sin x)/x = 1, lim x→0 (1−cos x)/x = 0, lim x→0 (eˣ−1)/x = 1, lim x→a (xⁿ−aⁿ)/(x−a) = n·aⁿ⁻¹.

Quick Quiz

1. For f(x) = (x²−1)/(x−1), what is lim x→1 f(x)?

Factor: (x²−1)/(x−1) = (x+1) for x≠1, so the limit is 1+1 = 2. There is a removable hole at x=1.

2. If LHL = 3 and RHL = 5 at x = a, then at x = a the function has a…

Both one-sided limits are finite but unequal (3 ≠ 5), so the limit fails to exist — a jump discontinuity.

3. The value of lim x→0 (sin x)/x is:

This is a standard limit: lim x→0 (sin x)/x = 1 (with x in radians).
