Types of sets

  • Empty (null) set ∅ or { } — no elements, n = 0.
  • Finite / infinite — countable end vs no end.
  • Singleton — exactly one element.
  • Equal sets — same elements. Equivalent — same n.
  • Universal set U — contains all elements under discussion.

Operations

  • Union A∪B: in A or B (or both).
  • Intersection A∩B: in both A and B.
  • Difference A−B: in A but not B.
  • Complement A′ = U−A: not in A.
  • Symmetric difference A▵B: in exactly one of them.

Subset & power set

  • A ⊆ B if every element of A is in B.
  • ∅ and A itself are always subsets of A.
  • Power set P(A) = set of all subsets; n(P(A)) = 2n(A).
