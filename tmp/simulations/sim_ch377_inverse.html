3 · Properties of the inverse & adjoint

  • Reversal law: (AB)⁻¹ = B⁻¹A⁻¹ — the inverse of a product is the product of inverses in reverse order.
  • Double inverse: (A⁻¹)⁻¹ = A.
  • Transpose: (Aᵀ)⁻¹ = (A⁻¹)ᵀ.
  • Scalar: (kA)⁻¹ = (1/k) A⁻¹, k ≠ 0.
  • Determinant: det(A⁻¹) = 1 / det(A).
  • Adjoint: A · adj(A) = adj(A) · A = det(A) I.
  • Adjoint det (nxn): det(adj A) = det(A)ⁿ⁻¹.

Adjoint (adjugate)

adj(A) is the transpose of the cofactor matrix. Cofactor Cij = (−1)i+j Mij, where Mij is the minor (determinant left after deleting row i, column j).

Inverse formula

A−1 = adj(A) / det(A), valid only when det(A) ≠ 0 (A is then non-singular / invertible). If det(A) = 0, A is singular and has no inverse.

Matrix method for AX = B

If det(A) ≠ 0: unique solution X = A−1B. If det(A) = 0 and (adj A)B = 0: infinitely many solutions. If det(A) = 0 and (adj A)B ≠ 0: no solution (inconsistent).
