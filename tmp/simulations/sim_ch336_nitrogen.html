The Nitrogen Cycle

Nitrogen is needed for amino acids, proteins, nucleic acids, ATP and chlorophyll. Atmospheric N₂ is inert, so it must be fixed before life can use it.

Select a step to see the organisms and reactions.

Biological Nitrogen Fixation

Certain prokaryotes reduce N₂ to NH₃. Symbiotic: Rhizobium in legume root nodules, Frankia in Alnus. Free-living: aerobic Azotobacter, anaerobic Clostridium, and cyanobacteria Anabaena, Nostoc.

Assimilation of Nitrate

Roots absorb NO₃⁻. It is reduced stepwise to NH₄⁺, which is toxic if it accumulates, so it is rapidly built into amino acids and never released free.

Key Facts

  • Only prokaryotes fix nitrogen; no eukaryote makes nitrogenase.
  • Nitrogenase is irreversibly inactivated by O₂ → nodules use leghaemoglobin (an O₂ scavenger) to keep O₂ very low while still supplying it to bacteroids by controlled release.
  • Fixation is costly: N₂ + 8H⁺ + 8e⁻ + 16 ATP → 2NH₃ + H₂
  • Nitrification is aerobic: Nitrosomonas (NH₃→NO₂⁻) then Nitrobacter (NO₂⁻→NO₃⁻).
  • Denitrification (Pseudomonas, Thiobacillus) returns N₂ to air under anaerobic soil.
  • Ammonification: decomposers convert dead organic-N back to NH₃/NH₄⁺.
