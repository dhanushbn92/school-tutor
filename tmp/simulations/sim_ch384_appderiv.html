Key Facts

Increasing / Decreasing test

  • If f′(x) > 0 on an interval, f is increasing there.
  • If f′(x) < 0 on an interval, f is decreasing there.

First derivative test (local extrema)

  • At a critical point where f′(c)=0: if f′ changes + → − it is a local maximum; if − → + a local minimum.

Second derivative test

  • If f′(c)=0 and f″(c) < 0 → local maximum; if f″(c) > 0 → local minimum.
  • A point of inflection is where concavity changes: f″(x)=0 with a sign change.

Tangent & normal at (x₀, y₀)

  • Tangent slope = f′(x₀); normal slope = −1 / f′(x₀) (normal ⟂ tangent).
  • Tangent: y − y₀ = f′(x₀)(x − x₀).

Optimization

  • Write the quantity as a function of one variable, set f′(x)=0, solve, then test with f′ or f″.

Quick Quiz

1. For f(x) = x³ − 3x, at which x is there a local maximum?

f′(x)=3x²−3=0 → x=±1. f″(x)=6x; f″(−1)=−6<0, so x=−1 is a local maximum.

2. The slope of the normal to a curve at a point where f′(x₀)=2 is:

Normal slope = −1/f′(x₀) = −1/2.

3. Cutting squares of side x from a 24×24 sheet, the box volume is maximum at:

V=x(24−2x)²; V′=12(x−4)(x−12)=0 → x=4 (x=12 gives V=0). Max at x=4.
