Empirical Relation & When to Use

For a moderately skewed distribution: Mode = 3 × Median − 2 × Mean

Which measure to use?

Mean
Uses every value; best for symmetric data. Sensitive to outliers — one extreme value distorts it.
Median
Middle value; unaffected by outliers. Best for skewed data or incomes.
Mode
Most frequent value; the only measure for qualitative/categorical data (e.g. most common shoe size).

Facts & Formulas

Mean (ungrouped)
x̄ = (Σxᵢ) / n
Median (ungrouped)
Sort the data. If n is odd, median = the ((n+1)/2)th value. If n is even, median = average of the (n/2)th and (n/2+1)th values.
Mode (ungrouped)
The value(s) that occur most often.
Grouped mean — direct
x̄ = Σfᵢxᵢ / Σfᵢ where xᵢ is the class mark (mid-point).
Grouped mean — assumed
x̄ = a + (Σfᵢdᵢ / Σfᵢ), dᵢ = xᵢ − a.
Grouped mean — step-deviation
x̄ = a + h × (Σfᵢuᵢ / Σfᵢ), uᵢ = (xᵢ − a)/h.
Grouped median
Median = l + ((n/2 − cf) / f) × h
l = lower boundary of median class, n = Σf, cf = cumulative freq before median class, f = freq of median class, h = class width.
Grouped mode
Mode = l + ((f₁ − f₀) / (2f₁ − f₀ − f₂)) × h
l = lower boundary of modal class, f₁ = modal freq, f₀ = freq before, f₂ = freq after, h = class width.
Empirical relation
Mode = 3 Median − 2 Mean
