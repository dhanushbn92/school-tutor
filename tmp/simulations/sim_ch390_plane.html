Key facts — the plane

  • General (Cartesian): ax + by + cz = d. The coefficient vector n = (a, b, c) is normal (perpendicular) to the plane.
  • Vector form: r·n = d, and normal form r·n̂ = p, where n̂ is the unit normal and p = d/|n| is the perpendicular distance from the origin.
  • Intercept form: x/A + y/B + z/C = 1, where A = d/a, B = d/b, C = d/c are the intercepts on the axes.
  • Distance of point P(x₀,y₀,z₀): |ax₀+by₀+cz₀−d| / √(a²+b²+c²).
  • Angle between planes: cos θ = (n₁·n₂)/(|n₁||n₂|), using the two normals.
  • Parallel: a₁/a₂ = b₁/b₂ = c₁/c₂ (normals proportional). Perpendicular: a₁a₂+b₁b₂+c₁c₂ = 0.
  • Through 3 points A,B,C: normal n = (B−A)×(C−A); plane is n·(r−A)=0.

Quick check (3 questions)

1. What is the normal vector to the plane 3x − 2y + z = 7?

The coefficients of x, y, z form the normal: n = (3, −2, 1).

2. The distance of the point (1, 2, 2) from the plane 2x + y + 2z = 3 is:

|2·1+1·2+2·2 − 3| / √(4+1+4) = |8−3|/3 = 5/3.

3. Two planes with normals (1, 0, 1) and (1, 0, −1) are:

n₁·n₂ = 1·1 + 0 + 1·(−1) = 0, so the planes are perpendicular.
