CHAPTER 2 — POLYNOMIALS

Introduction

In Chapter 1 you studied numbers and their properties. From now on we move to ALGEBRAIC EXPRESSIONS — letters that stand for numbers — and the most useful kind, POLYNOMIALS. You met polynomials in Class 9; here we go further: we look at the link between a polynomial's ZEROES and its coefficients, and at the division algorithm for polynomials. Two big results stand out — the relations between zeros and coefficients (for quadratic and cubic polynomials), and the division algorithm.


2.1 RECAP OF POLYNOMIALS

A POLYNOMIAL p(x) in one variable x is an expression of the form
    p(x) = aₙ xⁿ + aₙ₋₁ xⁿ⁻¹ + … + a₁ x + a₀,
where the coefficients a₀, a₁, …, aₙ are real numbers, n is a non-negative integer, and aₙ ≠ 0. The DEGREE of p(x) is n.

By degree:
- Degree 0 — constant polynomial. e.g. p(x) = 7.
- Degree 1 — linear. e.g. p(x) = 2x + 5.
- Degree 2 — quadratic. e.g. p(x) = x² − 3x + 2.
- Degree 3 — cubic. e.g. p(x) = x³ − 6x² + 11x − 6.
- Degree 4 — biquadratic.

The VALUE of a polynomial at a number a is p(a) — what you get by substituting x = a.


2.2 ZEROES OF A POLYNOMIAL

A ZERO (or root) of a polynomial p(x) is a value of x for which p(x) = 0. So 'zero of p' = 'root of the equation p(x) = 0'.

Examples.
- For p(x) = x² − 5x + 6: substitute x = 2 → 4 − 10 + 6 = 0. So x = 2 IS a zero. Similarly x = 3 is a zero. So this quadratic has TWO zeros.
- For p(x) = x − 7: x = 7 is the only zero.
- For p(x) = x² + 1: NO real zero (squaring gives a positive, plus one is always > 0). The zeros are complex (out of scope at this level).

GEOMETRICAL MEANING. The graph y = p(x) crosses the x-axis exactly at the real zeros of p. So 'how many real zeros does p have?' is the same as 'how many times does the graph cross the x-axis?'.

For a quadratic y = ax² + bx + c, the graph is a PARABOLA. Three cases (driven by the discriminant b² − 4ac):
- D > 0: parabola crosses the x-axis at TWO points → two distinct real zeros.
- D = 0: parabola TOUCHES the x-axis at one point → one real zero (with multiplicity 2).
- D < 0: parabola does not cross the x-axis → no real zeros.

For a polynomial of degree n, there can be AT MOST n real zeros.


2.3 RELATIONSHIP BETWEEN ZEROES AND COEFFICIENTS — QUADRATIC

For a quadratic p(x) = ax² + bx + c with zeroes α, β:
- Sum of zeroes:    α + β = −b/a.
- Product of zeroes: α β = c/a.

Why? Because we can factor a quadratic with zeroes α, β as
    p(x) = a (x − α)(x − β) = a [x² − (α + β)x + αβ].

Comparing with ax² + bx + c we read off the relations.

This is incredibly useful. If you know α + β and αβ, you can write a quadratic having α and β as zeros:
    p(x) = x² − (sum)·x + (product).

Example. Find a quadratic whose zeros are 2 and −3. Sum = −1; product = −6. So p(x) = x² − (−1)·x + (−6) = x² + x − 6.

Example. If α and β are zeros of x² − 5x + 6, find α + β, αβ, α² + β².
- a = 1, b = −5, c = 6. So α + β = −b/a = 5; αβ = c/a = 6.
- α² + β² = (α + β)² − 2αβ = 25 − 12 = 13.


2.4 RELATIONSHIP BETWEEN ZEROES AND COEFFICIENTS — CUBIC

For a cubic p(x) = ax³ + bx² + cx + d with zeroes α, β, γ:
- Sum:                   α + β + γ = −b/a.
- Sum of pair products:  αβ + βγ + γα = c/a.
- Product:               α β γ = −d/a.

The pattern: alternating signs, going down (b/a, c/a, d/a), with the n-th symmetric function appearing alongside (−1)ⁿ · the corresponding coefficient ratio. (At Class 10 the quadratic and cubic relations are the focus.)

Example. p(x) = x³ − 6x² + 11x − 6. a = 1, b = −6, c = 11, d = −6.
- Sum α + β + γ = −b/a = 6.
- Sum of pair products = c/a = 11.
- Product αβγ = −d/a = 6.
- The zeros turn out to be 1, 2, 3 (you can verify: 1 + 2 + 3 = 6; 1·2 + 2·3 + 1·3 = 11; 1·2·3 = 6 ✓).


2.5 DIVISION ALGORITHM FOR POLYNOMIALS

You learned long division for integers. Polynomials follow a similar pattern.

DIVISION ALGORITHM. Given polynomials p(x) (the dividend) and g(x) (the divisor), with g(x) ≠ 0, there exist UNIQUE polynomials q(x) (the quotient) and r(x) (the remainder) such that
    p(x) = g(x) · q(x) + r(x),
where either r(x) = 0 OR degree of r(x) < degree of g(x).

This is the polynomial analogue of Euclid's division lemma for integers.

Long division procedure for polynomials.
1. Arrange both polynomials in DECREASING order of degree.
2. Divide the highest-degree term of dividend by the highest-degree term of divisor — that gives the first term of the quotient.
3. Multiply the divisor by this term and SUBTRACT from the dividend.
4. Repeat with the new (lower-degree) dividend.
5. Stop when the remaining polynomial has degree less than the divisor.

Example. Divide p(x) = 3x³ + x² + 2x + 5 by g(x) = x² + 2x + 1.

Step 1: 3x³ ÷ x² = 3x. Multiply: 3x · (x² + 2x + 1) = 3x³ + 6x² + 3x. Subtract from p(x): (3x³ + x² + 2x + 5) − (3x³ + 6x² + 3x) = −5x² − x + 5.

Step 2: −5x² ÷ x² = −5. Multiply: −5 · (x² + 2x + 1) = −5x² − 10x − 5. Subtract: (−5x² − x + 5) − (−5x² − 10x − 5) = 9x + 10.

Now degree of (9x + 10) = 1, less than degree of g (which is 2). Stop.
Quotient q(x) = 3x − 5; Remainder r(x) = 9x + 10.

Verify: g(x)·q(x) + r(x) = (x² + 2x + 1)(3x − 5) + (9x + 10) = (3x³ + 6x² + 3x − 5x² − 10x − 5) + (9x + 10) = 3x³ + x² + 2x + 5 = p(x) ✓.


SUMMARY

- A polynomial p(x) = aₙxⁿ + … + a₁x + a₀ has degree n (the highest power of x).
- Linear, quadratic, cubic, biquadratic correspond to degrees 1, 2, 3, 4.
- A zero (root) of p is x with p(x) = 0.
- A polynomial of degree n has at most n real zeros.
- Geometrically, real zeros are x-axis crossings of y = p(x).
- For ax² + bx + c with zeros α, β: α + β = −b/a, αβ = c/a.
- For ax³ + bx² + cx + d with zeros α, β, γ: α + β + γ = −b/a, αβ + βγ + γα = c/a, αβγ = −d/a.
- Division algorithm: p(x) = g(x)·q(x) + r(x) with r = 0 or deg r < deg g.
- Polynomial long division mirrors integer long division.
