CHAPTER 5 — LINEAR EQUATIONS

Introduction

An equation is a statement that two algebraic expressions are equal. The expressions are joined by an equals sign (=). Solving an equation means finding the values of the variable(s) that make the two sides equal.

When the variable appears only to the first power and never multiplies itself or any other variable, the equation is called LINEAR. Linear equations are the simplest equations of all, and they are everywhere — from the formula for converting Celsius to Fahrenheit, to balancing a chequebook, to the constraints in a logistics problem. This chapter develops the techniques for solving linear equations in one variable, then in two variables (where two equations are needed), and finishes with the word problems that translate real situations into algebra.


5.1 LINEAR EQUATION IN ONE VARIABLE

A linear equation in one variable has the standard form
    ax + b = 0,    a ≠ 0,
where a and b are constants and x is the variable. Equivalent forms include 3x = 12, 2x + 5 = 11 and (x − 1)/4 = 7. Each can be re-arranged into the standard ax + b = 0.

The solution of an equation is the value of the variable that makes the equation true. For ax + b = 0, the unique solution is x = −b/a.

Examples.
- 3x − 6 = 0 has solution x = 2.
- 2x + 5 = 11 ⇒ 2x = 6 ⇒ x = 3.
- (x − 1)/4 = 7 ⇒ x − 1 = 28 ⇒ x = 29.

Verification. Substitute the candidate solution into the ORIGINAL equation; if both sides match, the solution is correct.


5.2 SOLVING LINEAR EQUATIONS IN ONE VARIABLE

Equality properties. The two sides of an equation can be transformed by the following rules without changing the truth set:
1. Add the same number (or expression) to both sides.
2. Subtract the same number from both sides.
3. Multiply both sides by the same NON-ZERO number.
4. Divide both sides by the same NON-ZERO number.

Strategy. To solve a linear equation:
1. Clear denominators by multiplying both sides by the LCM.
2. Remove brackets using the distributive law.
3. Bring all variable terms to one side and all constant terms to the other.
4. Combine like terms.
5. Divide by the coefficient of the variable.
6. Verify by substitution.

Worked example. Solve 3(x − 2) + 4 = 2x + 1.
    3(x − 2) + 4 = 2x + 1
    3x − 6 + 4 = 2x + 1     (distribute)
    3x − 2 = 2x + 1
    3x − 2x = 1 + 2          (move x to left, constants to right)
    x = 3.
Verify: LHS = 3(3 − 2) + 4 = 3 + 4 = 7; RHS = 2·3 + 1 = 7. ✓

Worked example with denominators. Solve x/2 + (x + 1)/3 = 4.
    LCM of 2 and 3 is 6. Multiply both sides by 6:
    3x + 2(x + 1) = 24
    3x + 2x + 2 = 24
    5x = 22
    x = 22/5.


5.3 WORD PROBLEMS — ONE VARIABLE

The art of translating a word problem into algebra is the heart of this section. The general routine is:
1. Read the problem twice, slowly.
2. Decide what is unknown and let x stand for it.
3. Translate each sentence into algebra.
4. Form ONE equation in x.
5. Solve.
6. Translate back into the language of the problem and verify.

Example A — number puzzle.
The sum of three consecutive odd integers is 75. Find the integers.
- Let x = the smallest. The next two odd integers are x + 2 and x + 4.
- x + (x + 2) + (x + 4) = 75 ⇒ 3x + 6 = 75 ⇒ x = 23.
- The integers are 23, 25, 27. (Verify: 23 + 25 + 27 = 75 ✓.)

Example B — age problem.
Anita's father is 4 times as old as Anita. After 6 years, the father will be only 3 times as old as Anita. Find the present ages.
- Let Anita's present age = x; father's present age = 4x.
- After 6 years: father = 4x + 6, Anita = x + 6.
- 4x + 6 = 3(x + 6) ⇒ 4x + 6 = 3x + 18 ⇒ x = 12.
- Anita is 12 years old; father is 48 years old.

Example C — distance / speed.
A boat goes 30 km downstream and back in 7 hours. The current is 1 km/h. Find the boat's speed in still water.
- Let still-water speed = x km/h.
- Downstream speed = x + 1; upstream = x − 1.
- 30/(x + 1) + 30/(x − 1) = 7.
- After clearing denominators (multiply by (x + 1)(x − 1)) one obtains a quadratic — but THIS chapter restricts to linear equations, so we'll revisit such problems in Chapter 6. The point: not every word problem is linear; recognise the type before choosing a method.


5.4 LINEAR EQUATIONS IN TWO VARIABLES

A linear equation in two variables x and y has the standard form
    ax + by + c = 0,    where a, b are not both zero.

A solution is an ORDERED PAIR (x, y) that satisfies the equation. Examples:
- 2x + 3y = 12 has solutions (0, 4), (3, 2), (6, 0), (−3, 6) and infinitely many more — any (x, (12 − 2x)/3).
- y = 2x + 1 has solutions (0, 1), (1, 3), (2, 5), …

Geometrically, the solution set of one linear equation in two variables is a STRAIGHT LINE in the xy-plane. Drawing the line is just plotting two of its solutions and joining them.

Steps to draw the graph.
1. Solve for y (if convenient): y = (−ax − c)/b.
2. Pick two convenient x values; compute the corresponding y.
3. Plot the two points and draw a straight line through them.
4. Optional: include a third point as a check.

Example. Graph y = 2x + 1.
- x = 0 → y = 1; point (0, 1).
- x = 1 → y = 3; point (1, 3).
- x = −1 → y = −1; point (−1, −1).
- All three lie on a straight line.


5.5 SYSTEMS OF LINEAR EQUATIONS IN TWO VARIABLES

To pin down both x and y uniquely we need TWO equations. A pair of linear equations in the same two variables is called a SIMULTANEOUS SYSTEM. The standard form is
    a₁ x + b₁ y + c₁ = 0,
    a₂ x + b₂ y + c₂ = 0.

A solution of the system is an ordered pair (x, y) that satisfies BOTH equations.

Three cases occur.
- Unique solution (consistent and independent). The two lines intersect at a single point. Algebraically, a₁/a₂ ≠ b₁/b₂.
- No solution (inconsistent). The two lines are parallel — same slope, different intercept. Algebraically, a₁/a₂ = b₁/b₂ ≠ c₁/c₂.
- Infinitely many solutions (consistent and dependent). The two equations describe the SAME line. Algebraically, a₁/a₂ = b₁/b₂ = c₁/c₂.

Quick check on 2x + 3y = 6 and 4x + 6y = 12. Ratios: 2/4 = 3/6 = 6/12 = 1/2 — same line, infinitely many solutions.


5.6 METHODS OF SOLVING SIMULTANEOUS LINEAR EQUATIONS

Three algebraic methods are commonly used.

Method 1 — Substitution.
1. From one equation, express one variable in terms of the other.
2. Substitute into the OTHER equation.
3. Solve the resulting one-variable linear equation.
4. Back-substitute to find the second variable.

Example. Solve x + y = 7, x − y = 1.
From eq.1: y = 7 − x. Substitute in eq.2: x − (7 − x) = 1 ⇒ 2x − 7 = 1 ⇒ x = 4. Then y = 7 − 4 = 3. Solution: (4, 3).

Method 2 — Elimination (also called the addition / subtraction method).
1. Multiply each equation by an appropriate constant so that the coefficient of one variable becomes equal in magnitude (and opposite in sign, if you plan to add).
2. Add or subtract the equations to eliminate that variable.
3. Solve the resulting one-variable linear equation.
4. Back-substitute.

Example. Solve 3x + 2y = 16, 5x + 2y = 22.
Subtract eq.1 from eq.2: 2x = 6 ⇒ x = 3. Substitute into eq.1: 9 + 2y = 16 ⇒ y = 7/2. Solution: (3, 7/2).

Method 3 — Cross-multiplication.
For the system a₁ x + b₁ y + c₁ = 0, a₂ x + b₂ y + c₂ = 0, the unique solution is
    x / (b₁ c₂ − b₂ c₁) = y / (c₁ a₂ − c₂ a₁) = 1 / (a₁ b₂ − a₂ b₁).
This formula is fast once you've practised it; the symmetry makes it useful for problems where the coefficients have awkward forms.

Choose the method that fits: if one variable's coefficient is already 1 or −1, substitution is fastest; otherwise elimination usually wins.


5.7 WORD PROBLEMS — TWO VARIABLES

Word problems with two unknowns translate naturally into a system of two equations. The translation routine extends from §5.3:
1. Identify the two unknowns and name them x and y.
2. Translate two distinct facts in the problem into two equations.
3. Solve the system by any of the three methods.
4. Verify and translate back.

Example A — money.
Five pencils and three erasers cost ₹40; three pencils and two erasers cost ₹25. Find the price of each.
- Let x = price of a pencil, y = price of an eraser (in ₹).
- 5x + 3y = 40, 3x + 2y = 25.
- Eliminate y: multiply eq.1 by 2, eq.2 by 3 → 10x + 6y = 80, 9x + 6y = 75. Subtract: x = 5. From eq.2: 15 + 2y = 25 ⇒ y = 5.
- A pencil costs ₹5; an eraser costs ₹5.

Example B — speed.
A boat travels 24 km downstream in 3 hours and the same distance upstream in 4 hours. Find the speed of the boat in still water and the speed of the current.
- Let still-water speed = x km/h, current = y km/h.
- Downstream: x + y = 24/3 = 8.
- Upstream: x − y = 24/4 = 6.
- Add: 2x = 14 ⇒ x = 7; subtract: 2y = 2 ⇒ y = 1.
- Boat speed = 7 km/h; current = 1 km/h.


SUMMARY

- A linear equation has variables only to the first power.
- One-variable form: ax + b = 0 → x = −b/a.
- Solve by isolating x using the four equality properties: add/subtract, multiply/divide both sides.
- A linear equation in two variables ax + by + c = 0 has infinitely many solutions; geometrically, a straight line.
- Two equations are needed to pin down a pair (x, y) uniquely.
- Three cases for a 2×2 system: unique, none, or infinitely many — determined by the ratios a₁/a₂, b₁/b₂, c₁/c₂.
- Three solution methods: substitution, elimination, cross-multiplication. Choose by what's convenient.
- Word problems: name the unknown, translate sentence-by-sentence, form an equation (or two), solve, verify, translate back.
