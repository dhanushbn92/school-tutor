CHAPTER 6 — QUADRATIC EQUATIONS

Introduction

In Chapter 5 we learned to solve linear equations — equations in which the variable appears only to the first power. The next step in algebra is the QUADRATIC EQUATION, in which the variable appears to the second power but no higher. Quadratic equations describe parabolic trajectories (a stone thrown in the air), areas of rectangles given perimeter constraints, problems on speed and current, and many situations in physics and economics.

This chapter develops three solution methods (factorisation, completing the square, and the quadratic formula), the discriminant test for the nature of roots, and the link between roots and coefficients. We finish with word-problem translations.


6.1 STANDARD FORM OF A QUADRATIC EQUATION

A quadratic equation in the variable x is an equation of the form
    a x^2 + b x + c = 0,        a ≠ 0,
where a, b, c are real numbers. The condition a ≠ 0 is essential — without it the equation collapses to bx + c = 0, which is linear, not quadratic.

The leading term ax^2 makes the equation quadratic; b is the coefficient of the linear term; c is the constant term.

Examples.
- 2x^2 − 5x + 3 = 0 (a = 2, b = −5, c = 3).
- x^2 − 9 = 0 (a = 1, b = 0, c = −9).
- 3x^2 + x = 0 (a = 3, b = 1, c = 0).
- (x − 2)^2 = 5 expands to x^2 − 4x − 1 = 0.
- 2x^2 = 4x + 6 rearranges to 2x^2 − 4x − 6 = 0.

Always re-arrange a quadratic into the standard form before applying any method.


6.2 ROOTS (ZEROS) OF A QUADRATIC EQUATION

A ROOT (or zero, or solution) of a quadratic equation ax^2 + bx + c = 0 is a value of x that makes the left-hand side equal to zero. Geometrically, it is an x-intercept of the parabola y = ax^2 + bx + c.

Example. For x^2 − 5x + 6 = 0, substitute x = 2: 4 − 10 + 6 = 0 ✓. So 2 is a root. Substitute x = 3: 9 − 15 + 6 = 0 ✓. So 3 is also a root.

A quadratic equation has AT MOST TWO real roots. The number is determined by the discriminant (§6.6).


6.3 SOLUTION BY FACTORISATION

If we can factor ax^2 + bx + c as a product of two linear factors, then setting each factor to zero gives the roots.

Strategy.
1. Re-arrange to standard form.
2. Factor the trinomial — most often by splitting the middle term.
3. Set each factor equal to 0 and solve.

Example. Solve x^2 − 5x + 6 = 0.
- Factor: x^2 − 5x + 6 = (x − 2)(x − 3).
- Set each factor zero: x − 2 = 0 → x = 2; x − 3 = 0 → x = 3.
- Roots: 2 and 3.

Example. Solve 2x^2 − 7x + 3 = 0.
- a·c = 6; need sum −7, product 6 → (−1, −6).
- Split: 2x^2 − x − 6x + 3 = 0 → x(2x − 1) − 3(2x − 1) = 0 → (2x − 1)(x − 3) = 0.
- Roots: x = 1/2 and x = 3.

Why this works. If P · Q = 0, then either P = 0 or Q = 0 (the ZERO-PRODUCT property). This is fundamental.

Limitation. Some quadratics don't factor over the rationals (their roots are irrational or complex); for those, use completing the square or the quadratic formula.


6.4 SOLUTION BY COMPLETING THE SQUARE

The technique writes the quadratic as a perfect-square trinomial plus or minus a constant, then takes square roots.

Procedure for ax^2 + bx + c = 0.
1. Divide both sides by a so the coefficient of x^2 is 1.
2. Move the constant to the right side: x^2 + (b/a) x = −c/a.
3. Add (b/(2a))^2 to both sides — this completes the square on the left.
4. Re-write the LHS as (x + b/(2a))^2.
5. Take square roots of both sides.
6. Solve for x.

Example. Solve x^2 − 6x + 5 = 0 by completing the square.
- x^2 − 6x = −5.
- Add (6/2)^2 = 9 to both sides: x^2 − 6x + 9 = 4.
- (x − 3)^2 = 4.
- x − 3 = ±2.
- x = 5 or x = 1.

Example. Solve 2x^2 + 8x − 10 = 0.
- Divide by 2: x^2 + 4x − 5 = 0 → x^2 + 4x = 5.
- Add (4/2)^2 = 4: x^2 + 4x + 4 = 9 → (x + 2)^2 = 9.
- x + 2 = ±3.
- x = 1 or x = −5.


6.5 THE QUADRATIC FORMULA

Completing the square on the general form ax^2 + bx + c = 0 yields:
    x = (−b ± √(b^2 − 4ac)) / (2a).

This is the QUADRATIC FORMULA. It works for ANY quadratic equation, regardless of whether the trinomial factors nicely.

Example. Solve 2x^2 + 5x − 3 = 0.
- a = 2, b = 5, c = −3.
- Discriminant b^2 − 4ac = 25 − 4·2·(−3) = 25 + 24 = 49.
- x = (−5 ± 7) / 4.
- x = 1/2 or x = −3.

Example. Solve x^2 − 4x + 1 = 0 (irrational roots).
- a = 1, b = −4, c = 1.
- Discriminant = 16 − 4 = 12.
- x = (4 ± √12) / 2 = (4 ± 2√3) / 2 = 2 ± √3.

The quadratic formula is the universal tool: when in doubt, use it.


6.6 NATURE OF ROOTS — THE DISCRIMINANT

The DISCRIMINANT of ax^2 + bx + c is
    D = b^2 − 4ac.

It tells us, without solving, the NATURE of the roots:
- If D > 0: two distinct real roots.
- If D = 0: two equal real roots (a repeated root, x = −b/(2a)).
- If D < 0: no real roots (the roots are complex conjugates; outside the scope of this chapter, but the parabola does not cross the x-axis).

Examples.
- x^2 − 5x + 6 = 0: D = 25 − 24 = 1 > 0, two distinct real roots.
- x^2 − 6x + 9 = 0: D = 36 − 36 = 0, equal real roots (both x = 3).
- x^2 + x + 1 = 0: D = 1 − 4 = −3 < 0, no real roots.

Geometric picture. The parabola y = ax^2 + bx + c crosses the x-axis at the real roots. D > 0 → two crossings; D = 0 → tangent to the x-axis; D < 0 → no crossing.


6.7 RELATIONSHIP BETWEEN ROOTS AND COEFFICIENTS

If α and β are the roots of ax^2 + bx + c = 0, then by the quadratic formula α + β = −b/a and α · β = c/a. So:
    SUM of roots = −b/a,
    PRODUCT of roots = c/a.

This lets us write down a quadratic given its roots:
    quadratic with roots α, β = (x − α)(x − β) = x^2 − (α + β)x + αβ.

Example. Find the quadratic whose roots are 3 and −5.
- Sum = 3 + (−5) = −2.
- Product = (3)(−5) = −15.
- Quadratic: x^2 − (−2) x + (−15) = x^2 + 2x − 15 = 0.

Example. If one root of x^2 + bx + 12 = 0 is 4, find the other root and b.
- Product of roots = 12 = 4 · β → β = 3.
- Sum = 4 + 3 = 7 = −b → b = −7.


6.8 WORD PROBLEMS LEADING TO QUADRATICS

Many real situations translate naturally into a quadratic equation: a piece of land with given area and a perimeter constraint; a journey at varying speed; consecutive integers whose product is given.

Routine.
1. Read carefully; identify the unknown(s) and let x stand for it.
2. Translate each fact into algebra; one of them must produce a quadratic in x.
3. Solve the quadratic.
4. CHECK both roots against the problem's context — REJECT roots that are non-physical (negative ages, negative speeds).
5. Translate back.

Example A — number puzzle.
The product of two consecutive positive integers is 132. Find them.
- Let smaller = x. Larger = x + 1. Product: x(x + 1) = 132.
- x^2 + x − 132 = 0. Factor: (x − 11)(x + 12) = 0. So x = 11 or x = −12.
- Reject x = −12 (must be positive). Integers: 11 and 12.

Example B — area.
A rectangular garden's length is 4 m more than its width, and its area is 192 m². Find the dimensions.
- Let width = x. Length = x + 4. Area: x(x + 4) = 192 → x^2 + 4x − 192 = 0.
- Discriminant: 16 + 768 = 784 = 28^2. x = (−4 ± 28)/2 = 12 or −16.
- Reject x = −16. Width = 12 m; length = 16 m.

Example C — speed and current.
A motorboat travels 24 km downstream and back in 7 hours. Speed of current is 3 km/h. Find the speed of the boat in still water.
- Let still-water speed = x km/h.
- Downstream time: 24/(x + 3). Upstream time: 24/(x − 3).
- Total: 24/(x + 3) + 24/(x − 3) = 7.
- Multiply through by (x + 3)(x − 3): 24(x − 3) + 24(x + 3) = 7(x^2 − 9) → 48x = 7x^2 − 63.
- 7x^2 − 48x − 63 = 0. Discriminant 48^2 + 4·7·63 = 2304 + 1764 = 4068. √4068 ≈ 63.78.
- x = (48 + 63.78)/14 ≈ 7.98 ≈ 8 (the negative root is rejected). The boat's still-water speed is approximately 8 km/h. (For an exact answer, factor 7x^2 − 48x − 63 = 0: a·c = −441, sum −48, factor pair (−63, 21) → 7x^2 + 21x − 63x − 63 ... nope; use the quadratic formula and round.) The student's intended exact value with cleaner data would be 8 km/h.


SUMMARY

- A quadratic equation has standard form ax^2 + bx + c = 0 with a ≠ 0.
- Roots are the values of x for which the LHS = 0; at most two real roots.
- Three solution methods:
  • Factorisation (works when factors are rational).
  • Completing the square (always works; reveals the perfect-square structure).
  • Quadratic formula x = (−b ± √(b^2 − 4ac))/(2a) — universal.
- Discriminant D = b^2 − 4ac:
  • D > 0 → two distinct real roots.
  • D = 0 → equal real roots (repeated).
  • D < 0 → no real roots.
- If α and β are the roots: α + β = −b/a; α · β = c/a.
- Quadratic with given roots α, β: x^2 − (α + β)x + αβ = 0.
- Word problems: name the unknown, set up the quadratic, solve, REJECT non-physical roots.
