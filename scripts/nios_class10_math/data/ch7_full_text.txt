CHAPTER 7 — ARITHMETIC PROGRESSIONS

Introduction

Many natural and everyday patterns are sequences in which each new term is obtained from the previous one by adding a fixed amount: the savings in a piggy bank if you add the same amount each week, the salary you earn if your annual raise is a fixed rupee amount, the lengths of the rungs of a tapered ladder, the distances covered each second by a body in uniform deceleration. Such sequences are called arithmetic progressions (APs). In this chapter we make the idea precise, derive a formula for the n-th term, derive two equivalent formulae for the sum of the first n terms, study the arithmetic mean of two numbers, and apply APs to short word problems.


7.1 SEQUENCES AND SERIES

A sequence is an ordered list of numbers, written
    a_1, a_2, a_3, a_4, …,
where a_1 is the first term, a_2 is the second term, and in general a_n is the n-th term. The sequence may have finitely many terms (a_1, a_2, …, a_m) or infinitely many.

A series is the sum of the terms of a sequence:
    S = a_1 + a_2 + a_3 + …
The partial sum of the first n terms is denoted S_n:
    S_n = a_1 + a_2 + … + a_n.

A sequence is completely described by giving a rule for a_n. Examples:
- a_n = 2 n: 2, 4, 6, 8, 10, … (the positive even numbers).
- a_n = 1/n: 1, 1/2, 1/3, 1/4, …
- a_n = (−1)^n: −1, +1, −1, +1, … (an alternating sequence).
- The Fibonacci sequence 1, 1, 2, 3, 5, 8, … is defined recursively: a_1 = a_2 = 1 and a_n = a_(n−1) + a_(n−2) for n ≥ 3.

In this chapter we focus on the simplest kind of sequence — one in which each term differs from its predecessor by the same amount.


7.2 ARITHMETIC PROGRESSION — DEFINITION

An arithmetic progression (AP) is a sequence in which the difference between any two consecutive terms is a constant. That is, a sequence a_1, a_2, a_3, … is an AP if
    a_2 − a_1 = a_3 − a_2 = a_4 − a_3 = … = d
for some fixed real number d. The constant d is called the common difference of the AP, and a_1 is called the first term.

We sometimes write the first term as a (instead of a_1) for brevity. With first term a and common difference d, the AP is
    a, a + d, a + 2 d, a + 3 d, a + 4 d, …

Examples.
    3, 7, 11, 15, 19, …       (a = 3, d = 4).
    25, 22, 19, 16, …         (a = 25, d = −3).
    −5, −5, −5, −5, …         (a = −5, d = 0; a constant sequence is an AP).
    1/2, 1, 3/2, 2, 5/2, …    (a = 1/2, d = 1/2).
    100, 110, 120, …          (a = 100, d = 10; e.g. a salary that rises by ₹10 each step).

To check whether a given sequence is an AP, compute successive differences and verify they are all equal.

Examples (check).
    5, 9, 13, 17 → 9 − 5 = 4, 13 − 9 = 4, 17 − 13 = 4 ✓ AP, d = 4.
    1, 4, 9, 16 → 4 − 1 = 3, 9 − 4 = 5; not an AP (these are squares).
    2, 4, 8, 16 → differences 2, 4, 8; not constant — not an AP.

A finite AP has a finite number of terms; an infinite AP continues indefinitely. Both are studied in this chapter.


7.3 N-TH TERM OF AN AP

For an AP with first term a and common difference d, the terms are
    a_1 = a,
    a_2 = a + d,
    a_3 = a + 2 d,
    a_4 = a + 3 d,
    …
By inspection, the n-th term contains (n − 1) copies of d added to a:

    a_n = a + (n − 1) d.

This is the formula for the n-th term of an AP. It is the workhorse of every AP problem and should be memorised.

Examples.
1. Find the 12th term of the AP 5, 8, 11, 14, …
    a = 5, d = 3.
    a_12 = 5 + 11 × 3 = 5 + 33 = 38.

2. The 7th term of an AP is 23 and the 12th term is 38. Find the AP.
    a + 6 d = 23 and a + 11 d = 38. Subtracting: 5 d = 15, so d = 3.
    Then a = 23 − 18 = 5. The AP is 5, 8, 11, 14, …

3. Which term of the AP 7, 13, 19, 25, … is 205?
    a = 7, d = 6. Set a + (n − 1) d = 205, i.e. 7 + 6 (n − 1) = 205.
    6 (n − 1) = 198, so n − 1 = 33, n = 34. The 34th term is 205.

4. How many three-digit numbers are divisible by 7?
    The smallest is 105, the largest is 994; the AP is 105, 112, 119, …, 994 with d = 7.
    Solve 105 + 7 (n − 1) = 994: 7 (n − 1) = 889, so n − 1 = 127, n = 128.
    There are 128 such numbers.

Negative and zero common differences. d > 0 gives an increasing AP; d < 0 gives a decreasing AP; d = 0 gives a constant sequence. The formula a_n = a + (n − 1) d works in all three cases.


7.4 SUM OF THE FIRST N TERMS OF AN AP

Let S_n denote the sum of the first n terms of the AP a, a + d, a + 2 d, …:
    S_n = a + (a + d) + (a + 2 d) + … + (a + (n − 1) d).

A clever derivation, often credited to a young Carl Friedrich Gauss, runs as follows. Write the sum forward and then backward:
    S_n = a + (a + d) + (a + 2 d) + … + (a + (n − 1) d),
    S_n = (a + (n − 1) d) + (a + (n − 2) d) + … + a.

Add the two lines term by term. Each of the n columns sums to 2 a + (n − 1) d. So
    2 S_n = n × (2 a + (n − 1) d),
which gives the first formula:

    S_n = (n / 2) × (2 a + (n − 1) d).

Equivalently, write l = a_n = a + (n − 1) d for the last term in the partial sum. Then 2 a + (n − 1) d = a + l, so

    S_n = (n / 2) × (a + l),

i.e. the sum of the first n terms equals n times the average of the first and last terms. Use this form when the last term is given; use the first form when only a, d and n are known.

Examples.
1. Sum of the first 30 terms of the AP 2, 5, 8, …
    a = 2, d = 3, n = 30.
    S_30 = (30 / 2) × (2 × 2 + 29 × 3) = 15 × (4 + 87) = 15 × 91 = 1365.

2. Sum of the AP 1 + 2 + 3 + … + 100 (sum of first 100 natural numbers).
    a = 1, l = 100, n = 100.
    S_100 = (100 / 2) × (1 + 100) = 50 × 101 = 5050.
    More generally: 1 + 2 + 3 + … + n = n (n + 1) / 2.

3. Sum of the first 50 odd natural numbers.
    The AP is 1, 3, 5, …; a = 1, d = 2, n = 50.
    S_50 = (50 / 2) × (2 + 49 × 2) = 25 × 100 = 2500.
    More generally: 1 + 3 + 5 + … + (2 n − 1) = n^2.

4. Sum of the first 50 even natural numbers.
    The AP is 2, 4, 6, …; a = 2, d = 2, n = 50.
    S_50 = (50 / 2) × (4 + 49 × 2) = 25 × 102 = 2550.
    More generally: 2 + 4 + 6 + … + 2 n = n (n + 1).

Recovering a_n from S_n. If S_n is given as a function of n, then
    a_n = S_n − S_(n−1)   for n ≥ 2,    a_1 = S_1.
This is sometimes useful: if S_n = 3 n^2 + 2 n then a_1 = 3 + 2 = 5, a_2 = S_2 − S_1 = 16 − 5 = 11, a_3 = S_3 − S_2 = 33 − 16 = 17, so the AP is 5, 11, 17, … with d = 6.


7.5 ARITHMETIC MEAN

The arithmetic mean (AM) of two real numbers a and b is their average:
    AM(a, b) = (a + b) / 2.

If three numbers x, m, y are in AP (with m the middle term), then by the AP definition m − x = y − m, which rearranges to
    2 m = x + y, so m = (x + y) / 2.
That is, the middle term of three numbers in AP is the AM of the other two. Conversely, three numbers x, m, y are in AP iff m = (x + y) / 2.

To insert n arithmetic means between two given numbers a and b means to find n numbers m_1, m_2, …, m_n such that
    a, m_1, m_2, …, m_n, b
is an AP. This AP has (n + 2) terms, first term a and last term b. Hence
    b = a + (n + 1) d, so d = (b − a) / (n + 1),
and the inserted means are
    m_k = a + k × d = a + k × (b − a) / (n + 1)   for k = 1, 2, …, n.

Examples.
1. Find the AM of 8 and 22. AM = (8 + 22)/2 = 15.

2. Insert 3 arithmetic means between 4 and 24.
    Five-term AP: 4, m_1, m_2, m_3, 24. So d = (24 − 4) / 4 = 5. The means are 9, 14, 19. The AP is 4, 9, 14, 19, 24.

3. Insert 4 arithmetic means between 5 and 25.
    Six-term AP: 5, m_1, m_2, m_3, m_4, 25. So d = (25 − 5)/5 = 4. The means are 9, 13, 17, 21.


7.6 WORD PROBLEMS ON ARITHMETIC PROGRESSIONS

A standard AP word problem is solved in four steps:
1. Identify the quantity that changes by a constant amount; that is the AP.
2. Read the first term a and the common difference d (or two specific terms).
3. Choose the right formula: a_n = a + (n − 1) d for a single term, S_n = (n/2)(2 a + (n − 1) d) (or (n/2)(a + l)) for a sum.
4. Solve and report. Reject any non-natural-number value of n.

Example 1 (savings). A man saves ₹100 in the first month, ₹125 in the second, ₹150 in the third, and so on. (a) How much does he save in the 12th month? (b) How much does he save in the first 12 months in total?
    a = 100, d = 25.
    (a) a_12 = 100 + 11 × 25 = 100 + 275 = ₹375.
    (b) S_12 = (12/2)(2 × 100 + 11 × 25) = 6 × (200 + 275) = 6 × 475 = ₹2850.

Example 2 (rungs of a ladder). A ladder has 25 rungs. The lengths of the rungs form an AP; the longest rung (at the bottom) is 50 cm long and the shortest (at the top) is 25 cm long. Find the total length of all the rungs.
    a = 50 (longest), l = 25 (shortest), n = 25.
    S_25 = (25/2)(50 + 25) = (25/2)(75) = 937.5 cm.

Example 3 (theatre seating). A theatre has 30 rows of seats. The first row has 20 seats, and each successive row has 2 more seats than the row in front. How many seats are there in total?
    a = 20, d = 2, n = 30.
    S_30 = (30/2)(2 × 20 + 29 × 2) = 15 × (40 + 58) = 15 × 98 = 1470 seats.

Example 4 (which term). A man borrows ₹15000 and agrees to repay it in monthly instalments. The first instalment is ₹1500 and each subsequent instalment is ₹100 less than the previous one. After how many instalments will the loan be cleared?
    a = 1500, d = −100. We need n such that S_n = 15000.
    S_n = (n/2)(2 × 1500 + (n − 1)(−100)) = (n/2)(3000 − 100 n + 100) = (n/2)(3100 − 100 n) = 50 n (31 − n).
    Set 50 n (31 − n) = 15000 → n (31 − n) = 300 → n^2 − 31 n + 300 = 0.
    Discriminant 961 − 1200 = −239 < 0; no real n. So the loan cannot be cleared exactly with this rule — the rule needs adjustment in practice.
    (Compare with the cleaner version: first instalment ₹1000, decrement ₹50, debt ₹13500. Then S_n = (n/2)(2000 − 50(n − 1)) = 25 n (81 − n)/... etc. — work problems carefully.)

The point is that solving an AP word problem is mechanical once you correctly read off a, d (or l) and decide whether you want a single term or a sum.


SUMMARY

- A sequence a_1, a_2, a_3, … is an arithmetic progression if a_2 − a_1 = a_3 − a_2 = … = d (a constant), called the common difference.
- The n-th term is a_n = a + (n − 1) d, where a is the first term.
- Sum of the first n terms: S_n = (n / 2) × (2 a + (n − 1) d) = (n / 2) × (a + l), where l = a_n is the last term.
- Useful particular sums: 1 + 2 + … + n = n (n + 1)/2, 1 + 3 + 5 + … + (2 n − 1) = n^2, 2 + 4 + … + 2 n = n (n + 1).
- The arithmetic mean of two numbers a and b is (a + b)/2; three numbers x, m, y are in AP iff m = (x + y)/2.
- To insert n arithmetic means between a and b, take d = (b − a)/(n + 1).
- AP word problems: identify a and d (or l), choose between a_n and S_n, solve, and reject any non-natural-number value of n.
