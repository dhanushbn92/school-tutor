CHAPTER 4 — SPECIAL PRODUCTS AND FACTORISATION

Introduction

In Chapter 3 we learned to multiply polynomials by repeatedly applying the distributive law. Some products come up so often that mathematicians have given them names and memorised their expanded forms — the "special products". Recognising one of these patterns lets us write the answer in one step instead of five.

Factorisation is the reverse problem: given a polynomial, can we write it as a product of simpler polynomials? Factorisation makes equations easier to solve, simplifies fractions, and reveals zeros at a glance. The two skills — special products and factorisation — work as a matched pair: the patterns we expand in §§4.1–4.3 are the very patterns we recognise (and reverse) in §§4.4–4.7.


4.1 SPECIAL PRODUCTS — SQUARE OF A BINOMIAL

Square of a sum.
    (a + b)^2 = a^2 + 2ab + b^2.

Derivation by FOIL:
    (a + b)(a + b) = a·a + a·b + b·a + b·b = a^2 + 2ab + b^2.

Square of a difference.
    (a − b)^2 = a^2 − 2ab + b^2.

Derivation:
    (a − b)(a − b) = a^2 − ab − ba + b^2 = a^2 − 2ab + b^2.

Both identities have the same SHAPE: square the first, twice the product, square the second — only the middle sign changes. The right-hand side is called a perfect-square trinomial.

Examples.
- (x + 5)^2 = x^2 + 10x + 25.
- (3y − 2)^2 = 9y^2 − 12y + 4.
- (2a + 7b)^2 = 4a^2 + 28ab + 49b^2.

Common slip: writing (a + b)^2 = a^2 + b^2. The middle term 2ab is essential.


4.2 SPECIAL PRODUCTS — DIFFERENCE OF SQUARES AND PRODUCT-SUM

Difference of squares.
    (a + b)(a − b) = a^2 − b^2.

Derivation:
    (a + b)(a − b) = a^2 − ab + ba − b^2 = a^2 − b^2.

This is a "shape": (sum) × (difference of the same two things) = (square minus square). The middle terms cancel.

Examples.
- (x + 7)(x − 7) = x^2 − 49.
- (2p + 3q)(2p − 3q) = 4p^2 − 9q^2.
- 103 × 97 = (100 + 3)(100 − 3) = 10000 − 9 = 9991. (Mental arithmetic from algebra!)

Product (x + a)(x + b) = x^2 + (a + b)x + ab.

Derivation:
    (x + a)(x + b) = x·x + x·b + a·x + a·b = x^2 + (a + b)x + ab.

This is the SHAPE we will reverse in §4.6 to factorise quadratics like x^2 + 5x + 6.

Example: (x + 2)(x + 3) = x^2 + 5x + 6 — coefficient of x is 2 + 3, constant term is 2 · 3.


4.3 SPECIAL PRODUCTS — CUBES

Cube of a sum.
    (a + b)^3 = a^3 + 3a^2 b + 3ab^2 + b^3.

Cube of a difference.
    (a − b)^3 = a^3 − 3a^2 b + 3ab^2 − b^3.

Both follow from squaring then multiplying once more, e.g.
    (a + b)^3 = (a + b)·(a + b)^2 = (a + b)·(a^2 + 2ab + b^2) = a^3 + 3a^2 b + 3ab^2 + b^3.

Sum and difference of cubes (factor form).
    a^3 + b^3 = (a + b)(a^2 − ab + b^2),
    a^3 − b^3 = (a − b)(a^2 + ab + b^2).

These two identities will be used heavily for factoring cubic expressions.

Example. 27x^3 + 8 = (3x)^3 + 2^3 = (3x + 2)(9x^2 − 6x + 4).


4.4 FACTORISATION — TAKING OUT THE COMMON FACTOR

Factorisation reverses multiplication. The first step in any factorisation is to look for a factor common to every term and pull it out.

Steps.
1. Find the HCF (greatest common factor) of all terms — both the numerical coefficients and the variable parts.
2. Divide every term by that HCF.
3. Write the original expression as HCF × (sum of quotients).

Examples.
- 6x^2 + 9x = 3x(2x + 3). [Common factor: 3x]
- 12a^2 b − 18ab^2 = 6ab(2a − 3b). [Common: 6ab]
- 5(x − 1) + 7(x − 1)^2 = (x − 1)(5 + 7(x − 1)) = (x − 1)(7x − 2). [Common factor: (x − 1)]


4.5 FACTORISATION — REGROUPING

When no factor is common to all terms, we can sometimes group terms in pairs (or larger sub-groups) so that each sub-group has its own common factor, and the resulting parts share a common BINOMIAL factor.

Example. Factorise ax + ay + bx + by.
    Group: (ax + ay) + (bx + by).
    Pull out from each: a(x + y) + b(x + y).
    Now (x + y) is a common factor: (x + y)(a + b).

Example. Factorise x^3 − 3x^2 + 4x − 12.
    Group: (x^3 − 3x^2) + (4x − 12).
    Pull out: x^2(x − 3) + 4(x − 3).
    Common: (x − 3)(x^2 + 4).

The art of regrouping is choosing pairings whose pulled-out factors match. If a first attempt does not work, try a different grouping.


4.6 FACTORISATION — QUADRATIC TRINOMIALS

This is the most important factoring technique in the chapter.

Type A: x^2 + bx + c (leading coefficient 1).
Find two numbers whose SUM is b and whose PRODUCT is c. The factorisation is (x + p)(x + q) where p + q = b and p·q = c.

Example. Factorise x^2 + 5x + 6.
- Need p + q = 5 and p·q = 6.
- Try (2, 3): 2 + 3 = 5, 2·3 = 6. ✓
- So x^2 + 5x + 6 = (x + 2)(x + 3).

Example. Factorise x^2 − 7x + 12.
- Need p + q = −7 and p·q = 12.
- Both negative (sum negative, product positive): try (−3, −4). ✓
- x^2 − 7x + 12 = (x − 3)(x − 4).

Type B: ax^2 + bx + c with a ≠ 1 — splitting the middle term.
Find two numbers whose SUM is b and whose PRODUCT is a·c. Split bx into those two terms, then regroup.

Example. Factorise 3x^2 + 11x + 6.
- a·c = 3·6 = 18. Need two numbers with sum 11 and product 18.
- Try (2, 9): 2 + 9 = 11, 2·9 = 18. ✓
- Split: 3x^2 + 2x + 9x + 6.
- Regroup: x(3x + 2) + 3(3x + 2) = (3x + 2)(x + 3).

Example. Factorise 2x^2 − 7x + 3.
- a·c = 6. Need sum −7, product 6: (−1, −6).
- Split: 2x^2 − x − 6x + 3.
- Regroup: x(2x − 1) − 3(2x − 1) = (2x − 1)(x − 3).


4.7 FACTORISATION — RECOGNISING THE SPECIAL-PRODUCT PATTERNS

Difference of squares: a^2 − b^2 = (a + b)(a − b).
- 49x^2 − 25 = (7x)^2 − 5^2 = (7x + 5)(7x − 5).
- 16a^4 − 81b^4 = (4a^2 − 9b^2)(4a^2 + 9b^2) = (2a − 3b)(2a + 3b)(4a^2 + 9b^2).

Perfect-square trinomial: a^2 ± 2ab + b^2 = (a ± b)^2.
- x^2 + 12x + 36 = (x + 6)^2 (since 36 = 6^2 and 12 = 2·6).
- 4y^2 − 20y + 25 = (2y − 5)^2 (since 25 = 5^2 and 20 = 2·2·5).

Sum / difference of cubes:
- x^3 + 27 = x^3 + 3^3 = (x + 3)(x^2 − 3x + 9).
- 8a^3 − 1 = (2a)^3 − 1^3 = (2a − 1)(4a^2 + 2a + 1).

Strategy for any factorisation problem:
1. Pull out the greatest COMMON factor first.
2. Look for a special-product pattern (difference of squares, perfect square, sum/diff of cubes).
3. If quadratic: split the middle term.
4. Otherwise: try regrouping.
5. Always check by re-multiplying.


SUMMARY

- Special products are named expansions worth memorising:
    (a ± b)^2 = a^2 ± 2ab + b^2,
    (a + b)(a − b) = a^2 − b^2,
    (x + a)(x + b) = x^2 + (a + b)x + ab,
    (a ± b)^3 = a^3 ± 3a^2 b + 3ab^2 ± b^3,
    a^3 ± b^3 = (a ± b)(a^2 ∓ ab + b^2).
- Factorisation is the reverse process: write a polynomial as a product.
- The general strategy: (i) common factor, (ii) special-product pattern, (iii) split-the-middle for quadratics, (iv) regrouping.
- Always verify by re-multiplying.
- Factorisation reveals zeros: if p(x) = (x − r)(x − s), then x = r and x = s are zeros. We will exploit this in the next chapters on linear and quadratic equations.
