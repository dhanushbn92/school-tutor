CHAPTER 7 — ARITHMETIC PROGRESSIONS

Introduction

Look around. The seats in a stadium row, the rungs of a ladder, monthly EMIs of equal amount, the number of bricks in stacked layers — all share a common feature. Each next item differs from the previous by the SAME fixed amount. Such an ordered list of numbers is called an ARITHMETIC PROGRESSION (AP).

This chapter develops the language of sequences and series, isolates APs, and introduces two workhorse formulas — the nth term aₙ and the sum of n terms Sₙ. With these two formulas you can answer almost every AP question that NIOS asks: find a particular term, find n given a target, find the first term and common difference from two given terms, and sum any finite stretch of an AP.


7.1 SEQUENCES AND ARITHMETIC PROGRESSIONS

A SEQUENCE is an ordered list of numbers, written a₁, a₂, a₃, … . Each member is called a TERM; the position counts from 1.

Examples of sequences:
- 2, 5, 8, 11, 14, …  (odd jumps of 3)
- 1, 4, 9, 16, 25, …  (the squares)
- 1, 1, 2, 3, 5, 8, … (Fibonacci)

An ARITHMETIC PROGRESSION (AP) is a sequence in which the difference between any two consecutive terms is the SAME constant. That constant is called the COMMON DIFFERENCE, written d.
    d = a₂ − a₁ = a₃ − a₂ = a₄ − a₃ = … = aₙ − aₙ₋₁.

The first term is denoted a (or a₁). An AP is therefore determined by the pair (a, d).

Notation: a, a + d, a + 2d, a + 3d, … is the standard form of an AP with first term a and common difference d.

How to test whether a list is an AP. Compute consecutive differences. If they are ALL equal, the list is an AP; if any one differs, it is NOT.

Examples.
- 5, 9, 13, 17, 21 → differences 4, 4, 4, 4. AP with a = 5, d = 4.
- 10, 7, 4, 1, −2 → differences −3, −3, −3, −3. AP with a = 10, d = −3 (decreasing AP).
- 1, 4, 9, 16 → differences 3, 5, 7. NOT an AP.

Sign of d. d > 0 → INCREASING AP; d < 0 → DECREASING AP; d = 0 → CONSTANT AP (all terms equal).

Finite vs infinite AP. An AP may have a fixed number of terms (FINITE) such as 2, 5, 8, …, 50 — in which case the LAST TERM (denoted l) is well-defined — or it may continue indefinitely (INFINITE).


7.2 THE GENERAL TERM aₙ

For an AP with first term a and common difference d, the nth term is
    aₙ = a + (n − 1) · d.

Why? a₁ = a, a₂ = a + d, a₃ = a + 2d, …; in general the (n−1) jumps of size d carry us from a₁ to aₙ.

Example. AP: 2, 5, 8, 11, … . Here a = 2, d = 3.
- a₁₀ = 2 + 9 · 3 = 29.
- a₂₀ = 2 + 19 · 3 = 59.

Reverse: given aₙ, find n. AP: 3, 7, 11, 15, … is a term equal to 99? Solve a + (n−1)d = 99: 3 + (n−1)·4 = 99 → n−1 = 24 → n = 25. So 99 is the 25th term.

Two-term recovery. If two terms aₘ and aₙ are known (m ≠ n), the common difference is
    d = (aₙ − aₘ) / (n − m),
and a follows from aₙ = a + (n−1)d.

Worked example. The 4th term of an AP is 14 and the 10th term is 38. Find the AP.
    d = (38 − 14)/(10 − 4) = 24/6 = 4.
    a₁ = a₄ − 3d = 14 − 12 = 2.
    AP: 2, 6, 10, 14, 18, 22, 26, 30, 34, 38, …

Last term of a finite AP. If the AP has n terms with last term l, then
    l = a + (n − 1) · d,
which is just aₙ with aₙ renamed l.


7.3 SUM OF FIRST n TERMS Sₙ

For an AP with first term a and common difference d, the sum of the first n terms is
    Sₙ = n/2 · [2a + (n − 1) · d].

If the last term l is known,
    Sₙ = n/2 · (a + l).

The two forms are equivalent: l = a + (n−1)d → 2a + (n−1)d = a + l.

Why does it work? Pair the first and last term, the second and second-last, etc. Each pair sums to a + l, and there are n/2 such pairs, giving the second form. The first form drops in by substituting l.

Example. Sum the first 20 terms of 5, 8, 11, 14, … . Here a = 5, d = 3, n = 20.
    S₂₀ = 20/2 · [2·5 + 19·3] = 10 · (10 + 57) = 10 · 67 = 670.

Example. Sum 2 + 4 + 6 + … + 100. AP with a = 2, d = 2; need n with l = 100: 100 = 2 + (n−1)·2 → n = 50.
    S₅₀ = 50/2 · (2 + 100) = 25 · 102 = 2550.

Example (a NIOS classic). Find the sum of the first n natural numbers, 1 + 2 + 3 + … + n.
    Sₙ = n/2 · (1 + n) = n(n + 1)/2.

Reverse direction — given Sₙ, find n.

Find n given that the sum 24 + 21 + 18 + … = 78. AP: a = 24, d = −3. Use Sₙ = n/2 · [2a + (n−1)d] = 78:
    n/2 · [48 − 3(n−1)] = 78 → n · [48 − 3n + 3] = 156 → n · (51 − 3n) = 156 → 51n − 3n² = 156 → n² − 17n + 52 = 0 → (n − 4)(n − 13) = 0 → n = 4 or n = 13.

(Both are valid: at n = 4 the sum momentarily reaches 78; the AP keeps decreasing; the running total returns to 78 at n = 13.)


7.4 ARITHMETIC MEAN

The ARITHMETIC MEAN (AM) of two numbers a and b is
    AM = (a + b) / 2.

If A is the AM of a and b, then a, A, b is itself a 3-term AP: the common difference is A − a = (b − a)/2.

Inserting n arithmetic means between a and b. Suppose we want the n-term AP a, A₁, A₂, …, Aₙ, b. There are (n+1) gaps from a to b, each of size d:
    d = (b − a) / (n + 1).
Then A_k = a + k · d for k = 1, 2, …, n.

Example. Insert 4 arithmetic means between 3 and 23.
    d = (23 − 3)/(4 + 1) = 4. AMs: 7, 11, 15, 19. Verify: 3, 7, 11, 15, 19, 23 — AP with d = 4. ✓


7.5 APPLICATIONS OF AP

APs model any quantity that changes by a fixed amount per step. Some standard NIOS scenarios:

Loan / EMI in equal instalments. A debt is repaid in equal instalments — the running outstanding balance forms a decreasing AP.

Salary increment. A starting salary with a fixed annual increment; the salary in the kth year is a + (k−1)d.

Number of seats / bricks / pipes. Stacked rows: bottom row has 100 bricks, each row above has 2 fewer; the row counts form a decreasing AP.

Production schedule. A factory makes 50 units in week 1 and adds 10 each week; total production over the first n weeks is the sum of the AP.

Worked example (loan). Sita borrows ₹3000 and repays in 12 monthly instalments. The first instalment is ₹500 and each subsequent instalment decreases by ₹25. Find the total amount paid.
    AP: a = 500, d = −25, n = 12.
    S₁₂ = 12/2 · [2 · 500 + 11 · (−25)] = 6 · (1000 − 275) = 6 · 725 = ₹4350.

Worked example (savings). A boy saves ₹5 in week 1, ₹7 in week 2, ₹9 in week 3, and so on. How much does he save in 30 weeks?
    AP: a = 5, d = 2, n = 30. S₃₀ = 30/2 · [2 · 5 + 29 · 2] = 15 · (10 + 58) = 15 · 68 = ₹1020.


SUMMARY

- A sequence in which consecutive terms differ by a fixed constant is an ARITHMETIC PROGRESSION (AP).
- The common difference d = aₙ − aₙ₋₁ is the same for every n > 1.
- Standard form: a, a + d, a + 2d, … . The pair (a, d) determines the AP.
- nth term: aₙ = a + (n − 1) · d.
- If two terms aₘ, aₙ are known, d = (aₙ − aₘ)/(n − m).
- Sum of first n terms: Sₙ = n/2 · [2a + (n − 1) · d] = n/2 · (a + l) when the last term l is known.
- The arithmetic mean of a and b is (a + b)/2; inserting n AMs uses d = (b − a)/(n + 1).
- APs model any uniform-step process: loans, salaries, stacked rows, savings.
